# Источники базовых моделей

## MobileNetV2

- источник: [ONNX Model Zoo — MobileNetV2-7](https://github.com/onnx/models/blob/main/validated/vision/classification/mobilenet/model/mobilenetv2-7.onnx);
- назначение: извлечение transfer-признаков изображения перед локальным k-NN;
- лицензия: Apache License 2.0;
- размер исходного файла: около 13,5 МБ;
- SHA-256: `c1c513582d56afceff8516c73804e484c81c6a830712ab6d682253f4a3cd042f`.

Изображение преобразуется в RGB, короткая сторона масштабируется до 256 пикселей, затем берётся центральный фрагмент 224×224. Каналы нормализуются средними `[0.485, 0.456, 0.406]` и стандартными отклонениями `[0.229, 0.224, 0.225]`, указанными в документации модели. Выходной вектор из 1 000 значений L2-нормализуется перед обучением локального классификатора.
