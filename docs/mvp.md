# Границы первой версии

## Пользовательский сценарий

1. Создать карточку растения по фотографии.
2. Подтвердить один вариант из трёх предложенных видов или выбрать «не распознано».
3. Добавить симптомы и сведения об условиях содержания.
4. Получить структурированную оценку состояния и рекомендации.
5. Отметить выполненное действие по уходу.
6. Через заданный интервал добавить повторную фотографию.
7. Увидеть сравнение двух наблюдений и изменение оценки.

## Ограничения

- от трёх до пяти поддерживаемых видов комнатных растений;
- ограниченный набор признаков: пожелтение, пятна и видимые повреждения;
- ручной ввод влажности и температуры, симулятор показателей для демонстрации потока;
- сравнение одного выбранного листа при контролируемом ракурсе;
- отказ от оценки динамики при недостаточно похожих снимках;
- рекомендации только из проверенного каталога действий.

## Не входит в первую версию

- управление промышленными теплицами;
- гарантированное определение редких заболеваний;
- автоматическое лечение без подтверждения пользователя;
- собственное аппаратное устройство;
- социальная сеть и торговая площадка.

## Критерии готовности

- основной сценарий выполняется через веб-интерфейс;
- сервисы запускаются одной командой;
- контракты событий версионируются и проверяются автоматически;
- критические ветви политики принятия решений покрыты тестами;
- демонстрационные данные воспроизводимы;
- CI запускает проверки для каждого изменения.
