# ksqlDB

Файл `01-init.sql` создаёт исходные потоки, представление последних показателей среды, шестичасовые агрегаты, обогащённый поток наблюдений и предупреждения.

После запуска инфраструктуры применить запросы можно командой:

```bash
make ksql-init
```

Для ключей используется `plant_id`, поэтому события одного растения попадают в одну секцию потока. Все временные значения передаются как Unix time в миллисекундах.

Версионированные JSON Schema для шести входных и выходных потоков находятся в `contracts/events`. Поля `x-kafka-topic` и `x-kafka-key` фиксируют транспортный контракт рядом со структурой сообщения; примеры из `tests/fixtures/events` одновременно проверяются как вход потребителя и результат сериализации производителя.

Повторные показатели среды отфильтровываются по `event_id` в суточном окне. Шестичасовые агрегаты используют event time из `occurred_at` и принимают запоздавшие события в течение 24 часов. Реальный сценарий с Kafka и ksqlDB запускается командой `make test-streams`.
