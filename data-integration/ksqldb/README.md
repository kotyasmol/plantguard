# ksqlDB

Файл `01-init.sql` создаёт исходные потоки, представление последних показателей среды, шестичасовые агрегаты, обогащённый поток наблюдений и предупреждения.

После запуска инфраструктуры применить запросы можно командой:

```bash
make ksql-init
```

Для ключей используется `plant_id`, поэтому события одного растения попадают в одну секцию потока. Все временные значения передаются как Unix time в миллисекундах.
